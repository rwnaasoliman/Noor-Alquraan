أكاديمية نور القرآن — موقع Frontend فقط
========================================

محتويات المجلد
- index.html : الصفحة الرئيسية
- style.css  : التصميم والألوان والتجاوب مع الموبايل
- script.js  : تفاعلات الواجهة وروابط واتساب

طريقة التشغيل
1) فكّي ضغط الملف ZIP.
2) افتحي مجلد Noor_Academy_Website.
3) افتحي index.html في المتصفح، أو افتحي المجلد في VS Code.
4) يفضّل تثبيت إضافة Live Server في VS Code ثم الضغط بزر الفأرة الأيمن على index.html واختيار Open with Live Server.

مهم قبل النشر: إعداد رقم واتساب
1) افتحي script.js.
2) ابحثي عن:
   const WHATSAPP_NUMBER = "201000000000";
3) استبدلي الرقم التجريبي برقم الأكاديمية الحقيقي بصيغة دولية، أرقام فقط، بدون علامة + أو مسافات.
   مثال تنسيقي لمصر: 201012345678
4) احفظي الملف وجربي أزرار واتساب من الموقع.

ملاحظات
- هذا مشروع واجهة أمامية فقط؛ لا يحتوي على حسابات مستخدمين أو قاعدة بيانات أو بوابة دفع.
- الأسعار المعروضة ليست أرقامًا؛ الموقع يوجّه الزائر للسؤال عن الأسعار عبر واتساب حتى تضيف الإدارة الأسعار الفعلية.
- قسم المعلمين توضيحي، ويجب إضافة أسماء المعلمين وسيرهم بعد اعتمادها.
- يحتاج اتصالًا بالإنترنت لعرض خط Cairo من Google Fonts.
- روابط واتساب لن تعمل مع رقم تجريبي؛ يجب تغييره قبل النشر.
